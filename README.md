# Basic-Streamlit-Tutorial

- This is a hands-on code written with the Tech with Tim 15 min streamlit intro video, where different streamlit widgets are used like uploading csv file, summary, filter, selectbox, and line_chart to create a demo dashboard of the interactive visualization of the csv data file.

- Streamlit a very hassle-free on the go web app creating library that enables to make web page on data and ml work on the web without having need of any web dev expertise.
